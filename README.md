# HiDevLab 自动开机/抢卡助手

脚本文件：[`hidevlab-auto-power.user.js`](./hidevlab-auto-power.user.js)

## 安装

1. 在 Edge 安装并启用 Tampermonkey。
2. 打开脚本文件，复制全部内容到 Tampermonkey 的新脚本中并保存。
3. 回到 `https://hidevlab.huawei.com/online-develop`，右上角会出现“HiDevLab 抢卡助手”面板。

## 使用

- 面板会自动识别当前页面中的开发环境，并显示名称、规格描述与实时状态；请勾选要抢的目标。
- “全选已关机”可以一次勾选当前识别到的关机环境，“清空选择”会取消全部目标。
- 默认每 2.5 秒检查一次，最低限制为 1.5 秒；遇到“资源调度中”时，会先点“关闭”，再按“关闭后重试(ms)”立即重试。
- 未勾选目标时不会提交任何开机请求。
- 同一时间只处理一个页面流程：开机 → 确认 → 关闭调度提示 → 重新开机，直到检测到成功或你点击“停止”。
- 开机成功识别到“运行中/已开机/已启动”等状态后，会发送通知；默认随后停止。
- “自动点击确认开机”关闭时，脚本会点“开机”但把确认留给你手动完成。

## 本次页面观察

实际页面流程是：点击“开机” → 弹出“确认开机？” → 确定 → “资源调度中”。你的要求是把这个弹窗视为一次未抢到：点“关闭”后立即再次点“开机”，脚本现在按此逻辑循环。

脚本不调用隐藏接口、不绕过验证码或限流；停止脚本请点击面板的“停止”按钮，或直接在 Tampermonkey 中禁用脚本。
